# 안전한 첫 출근 — 현장실습 사전교육 11차시

고등학교 특수학급 학생을 위한 **현장실습 사전교육 11차시** 수업 자료입니다.
차시당 50분 분량이며, 한 페이지 안에서 11차시를 모두 열어 볼 수 있습니다.
수업 전개 과정(차시별 50분 타임라인)은 학교·학급 사정에 맞게 교사가 직접 구성하도록 제외했습니다.

**수업용 주소 → https://cmhsong.github.io/field-practicum-prep/**

## 담긴 것

차시마다 다음이 들어 있습니다.

- **학습목표 3개**
- **쉬운 말 사전** — 새 용어를 차시당 4개로 제한
- **수업 영상 2편** — 안전보건공단·고용노동부·한국장애인고용공단 등 공식 기관 영상 목록 링크
- **안전교육 자료** — 안전표지(금지·경고·지시·안내), 보호구, 기계 안전, 응급처치
- **읽기자료** — 실제 보도·제도 내용을 학생이 읽을 수 있게 다시 쓴 글 + 기사 검색 링크
- **관련 링크 2개** — 안전보건공단·고용노동부·인권위 등 차시 주제에 맞는 공식 기관
- **OX 퀴즈 10문항** — 화면에서 ○/×를 누르면 바로 채점(정답 ○5 : ×5), 인쇄도 가능
- **학습지** — 빈칸·O/X·선 잇기·순서·체크리스트·쓰기 (인쇄 가능)
- **교사용 지도 메모** — 수준 조절, 활동 운영 팁
- **자료 수정 탭** — 고칠 내용이 생기면 화면에서 바로 고쳐 적용

## 화면 사용법

- **차시 이동** — 상단 검정 바의 **드롭다운**에서 차시를 고릅니다. ◀ ▶ 버튼, 키보드 ← → 도 됩니다.
- **전체 화면 수업** — 오른쪽 위 `⛶ 전체 화면 수업` 버튼(또는 `F` 키). 글자가 커지고 머리말·푸터가 사라져 교실 TV·빔프로젝터에 띄우기 좋습니다. `✕` 또는 `Esc`로 빠져나옵니다.
- **진행률** — 드롭다운 옆 막대가 11차시 중 현재 위치를 보여 줍니다.
- **완료 도장** — 차시 제목 아래 `이 차시 다 들었어요`를 누르면 기기에 기록되어 다음에 열 때도 남습니다.
- **OX 퀴즈** — ○/×를 누르면 바로 채점되고, 10문항을 다 풀면 점수에 맞는 응원 메시지가 뜹니다.
- **교사 모드** — 오른쪽 위 `교사 모드` 버튼(`T` 키)으로 자료 수정 탭을 보이거나 숨깁니다. 기본은 숨김입니다.
- **최저임금 설정(8차시)** — 연도를 고르거나 새 금액을 입력하면 자료·학습지·정답이 함께 바뀝니다. 학습지 안에서도 `연도 바꾸기`로 바로 고를 수 있고, 인쇄물에는 적용 연도와 시급이 찍힙니다.

## 자료 수정 (교사용)

수정 탭은 **평소에 숨겨져 있습니다.** 오른쪽 위 `교사 모드` 버튼(또는 `T` 키)을 눌러야 나타나므로
학생에게 화면을 보여 줄 때 걸리적거리지 않습니다. 탭 안의 `이 탭 숨기기`로도 바로 끌 수 있고,
켜고 끈 상태는 그 기기에 기억됩니다. 꺼도 고친 내용은 그대로 적용된 채 남습니다.

차시마다 맨 아래에 **자료 수정** 탭이 있습니다. 내용이 바뀌거나 학급에 맞게 고칠 것이 생기면
파일을 건드리지 않고 화면에서 고쳐 바로 적용할 수 있습니다.

- **간단 수정** — 차시 제목, 한 줄 설명, 학습목표, 쉬운 말 사전, 수업 영상, 관련 링크,
  OX 퀴즈, 오늘의 정리, 교사용 메모를 줄 단위로 고칩니다.
  칸이 여러 개인 항목은 `|`로 나눕니다. 예) `낱말 | 뜻풀이`, `문장 | O`
- **전체(JSON)** — 학습지 문항·안전자료·읽기자료까지 그 차시 자료 전체를 고칩니다.
- **내보내기 · 불러오기** — 고친 내용을 복사해 다른 컴퓨터에 붙여 넣으면 그대로 옮겨집니다.
- **되돌리기** — `이 차시 원래대로` 또는 `모든 수정 지우기`로 처음 자료로 돌아갑니다.

고친 차시는 제목 옆에 **수정됨** 표시가 붙고, 수정 내용은 그 기기에 저장됩니다.
원본 자료(`src/page.html`)는 그대로 남아 있어, 되돌리면 언제든 처음 상태가 됩니다.
여러 선생님이 함께 쓸 자료로 굳히려면 수정 내용을 `src/page.html`에 옮겨 적고 다시 배포하세요.

## 인쇄

인쇄 버튼을 누르면 **A4 미리보기 창**이 먼저 열립니다. 실제 종이 크기(210×297mm)로
보면서 확인하고, 마음에 들면 `인쇄하기`를 누릅니다.

- **이 차시 학습지 인쇄** — 지금 보고 있는 차시의 학습지 1장
- **학습지 11장 모두 인쇄** — 11차시 학습지를 묶음으로(학생 파일 제작용)
- **이 퀴즈 인쇄 / 퀴즈 전체 인쇄** — OX 퀴즈를 지면 평가지로
- **차시 전체 인쇄** — 안전자료·읽기자료·퀴즈·학습지까지 한 묶음

미리보기 창에서 할 수 있는 것:

- **종이 위에서 바로 고치기** — 글자를 누르면 그 자리에서 고쳐집니다(학급 이름, 날짜,
  문항 문구 등). 고친 내용은 그 인쇄물에만 쓰이고 자료 원본은 그대로입니다.
- **글자 크게** — 시력이나 소근육이 약한 학생을 위해 본문을 키웁니다.
- **정답 표시** — 퀴즈 미리보기에서만 보이며, 교사용 채점본을 뽑을 때 씁니다.
- **닫기**(또는 `Esc`) — 인쇄하지 않고 돌아갑니다.

화면의 메뉴·버튼은 인쇄물에서 자동으로 빠집니다. 인쇄 창이 열리지 않으면 `Ctrl+P`(Mac `⌘P`)를 누르세요.
7차시 비상연락망, 9차시 도움카드, 10차시 성희롱 도움카드는 오려서 지갑에 넣는 양식입니다.

## 수업 전 확인할 것

1. **영상 링크는 기관 채널의 영상 "목록 검색"으로 연결됩니다.** 개별 영상 주소는 삭제·비공개로 자주 끊기기 때문입니다. 수업 전에 1편을 골라 2~5분 구간을 정해 주세요.
2. **최저임금은 8차시 화면에서 직접 바꿉니다.** 8차시의 **최저임금 설정** 탭에서 연도를 고르면(2021~2026 내장) 기준 표·학습지 계산 문항·교사용 정답에 한꺼번에 반영됩니다. 새 연도가 고시되면 **직접 입력** 탭에 연도와 시급을 넣어 저장하세요. 설정은 그 기기에 남습니다. 고시 금액은 [최저임금위원회](https://www.minimumwage.go.kr), 법령은 [국가법령정보센터](https://www.law.go.kr)에서 확인합니다.
3. **읽기자료는 교육용으로 다시 쓴 글입니다.** 실제 보도·제도를 바탕으로 했으나 기업·개인 이름은 넣지 않았습니다. 원문은 각 자료 아래 "기사 찾아보기" 링크에서 검색해 확인하세요.

## 수준 조절

읽기가 되고 짧은 문장을 이해하는 학생을 기준으로 작성했습니다.
더 낮은 수준의 학생이 함께 있는 학급에서는 학습지 1~2번만 쓰게 하고 나머지는
구두 응답으로 대체하는 방법을 각 차시 **교사용 지도 메모**에 적어 두었습니다.
OX 퀴즈 정답표도 그 메모 안에 있습니다.

## 9·10차시 운영 주의

직장 내 괴롭힘(9차시)과 성희롱 예방(10차시)은 과거 피해 경험이 드러날 수 있는 차시입니다.

- 수업 전 보호자에게 교육 실시를 안내하고, **수업 후 개별 면담 시간을 비워 두세요.**
- 피해가 드러나면 학교 성고충 처리 절차와 전문기관으로 즉시 연계합니다.
  (여성긴급전화 **1366** · 장애인권익옹호기관 **1644-8295** · 경찰 **112**)
- 카드 분류 활동에는 '괜찮은 행동' 카드를 절반 넣어, 모든 접촉을 두려워하게 만들지 않도록 균형을 잡습니다.
- 성희롱 예방 교육은 사업주의 법정 의무교육입니다(남녀고용평등법 제13조). 실습 기관이 교육을 실시하는지도 확인하세요.

## 고칠 때

`src/page.html`이 원본이고, 루트의 `index.html`은 빌드 결과물입니다.

```bash
# src/page.html 을 고친 뒤
node build.js        # → index.html 재생성
git add -A && git commit -m "내용 수정" && git push
```

`build.js`는 `<!doctype>`·charset·viewport 같은 문서 껍데기를 입히는 일만 합니다.
수업 내용은 `src/page.html` 안의 `SESSIONS` 배열에 차시별로 들어 있습니다.
차시를 하나 고치려면 그 차시의 `SESSIONS.push({ ... })` 블록만 보면 됩니다.
OX 퀴즈는 `QUIZ` 객체에 차시 번호별로 들어 있습니다.
퀴즈는 `["문장", 1]` 형식이고 `1`이 ○, `0`이 ×입니다. 정답표와 점수는 자동으로 만들어집니다.

| 파일 | 역할 |
|---|---|
| `src/page.html` | 원본. 수업 내용 전체(`SESSIONS` 배열)와 디자인·인쇄 CSS |
| `index.html` | 빌드 결과물. GitHub Pages가 이 파일을 서빙 |
| `build.js` | 원본에 HTML 문서 껍데기를 입혀 `index.html` 생성 |

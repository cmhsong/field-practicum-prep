# 안전한 첫 출근 — 현장실습 사전교육 11차시

고등학교 특수학급 학생을 위한 **현장실습 사전교육 11차시** 수업 자료입니다.
차시당 50분 분량이며, 한 페이지 안에서 11차시를 모두 열어 볼 수 있습니다.
수업 전개 과정(차시별 50분 타임라인)은 학교·학급 사정에 맞게 교사가 직접 구성하도록 제외했습니다.

**수업용 주소 → https://cmhsong.github.io/field-practicum-prep/**

## 담긴 것

차시마다 다음이 들어 있습니다.

- **학습목표 3개**
- **쉬운 말 사전** — 새 용어를 차시당 4개로 제한
- **수업 영상 2편** — 안전보건공단·고용노동부·한국장애인고용공단 등 공식 기관 영상 목록 링크
- **안전교육 자료** — 안전표지(금지·경고·지시·안내), 보호구, 기계 안전, 응급처치
- **읽기자료** — 실제 보도·제도 내용을 학생이 읽을 수 있게 다시 쓴 글 + 기사 검색 링크
- **OX 퀴즈 10문항** — 화면에서 ○/×를 누르면 바로 채점(정답 ○5 : ×5), 인쇄도 가능
- **학습지** — 빈칸·O/X·선 잇기·순서·체크리스트·쓰기 (인쇄 가능)
- **교사용 지도 메모** — 수준 조절, 활동 운영 팁

## 인쇄

- **이 차시 학습지 인쇄** — 지금 보고 있는 차시의 학습지 1장
- **학습지 11장 모두 인쇄** — 11차시 학습지를 묶음으로(학생 파일 제작용)
- **이 퀴즈 인쇄 / 퀴즈 전체 인쇄** — OX 퀴즈를 지면 평가지로
- **차시 전체 인쇄** — 안전자료·읽기자료·퀴즈·학습지까지 포함

A4 기준으로 맞춰져 있고, 화면의 메뉴·버튼은 인쇄물에서 자동으로 빠집니다.
7차시 비상연락망, 9차시 도움카드, 10차시 성희롱 도움카드는 오려서 지갑에 넣는 양식입니다.

## 수업 전 확인할 것

1. **영상 링크는 기관 채널의 영상 "목록 검색"으로 연결됩니다.** 개별 영상 주소는 삭제·비공개로 자주 끊기기 때문입니다. 수업 전에 1편을 골라 2~5분 구간을 정해 주세요.
2. **8차시 최저임금(2026년 적용 10,320원)과 법령 조항은 매년 바뀝니다.** [최저임금위원회](https://www.minimumwage.go.kr), [국가법령정보센터](https://www.law.go.kr)에서 당해 연도 기준을 확인하세요.
3. **읽기자료는 교육용으로 다시 쓴 글입니다.** 실제 보도·제도를 바탕으로 했으나 기업·개인 이름은 넣지 않았습니다. 원문은 각 자료 아래 "기사 찾아보기" 링크에서 검색해 확인하세요.

## 수준 조절

읽기가 되고 짧은 문장을 이해하는 학생을 기준으로 작성했습니다.
더 낮은 수준의 학생이 함께 있는 학급에서는 학습지 1~2번만 쓰게 하고 나머지는
구두 응답으로 대체하는 방법을 각 차시 **교사용 지도 메모**에 적어 두었습니다.
OX 퀴즈 정답표도 그 메모 안에 있습니다.

## 9·10차시 운영 주의

직장 내 괴롭힘(9차시)과 성희롱 예방(10차시)은 과거 피해 경험이 드러날 수 있는 차시입니다.

- 수업 전 보호자에게 교육 실시를 안내하고, **수업 후 개별 면담 시간을 비워 두세요.**
- 피해가 드러나면 학교 성고충 처리 절차와 전문기관으로 즉시 연계합니다.
  (여성긴급전화 **1366** · 장애인권익옹호기관 **1644-8295** · 경찰 **112**)
- 카드 분류 활동에는 '괜찮은 행동' 카드를 절반 넣어, 모든 접촉을 두려워하게 만들지 않도록 균형을 잡습니다.
- 성희롱 예방 교육은 사업주의 법정 의무교육입니다(남녀고용평등법 제13조). 실습 기관이 교육을 실시하는지도 확인하세요.

## 고칠 때

`src/page.html`이 원본이고, 루트의 `index.html`은 빌드 결과물입니다.

```bash
# src/page.html 을 고친 뒤
node build.js        # → index.html 재생성
git add -A && git commit -m "내용 수정" && git push
```

`build.js`는 `<!doctype>`·charset·viewport 같은 문서 껍데기를 입히는 일만 합니다.
수업 내용은 `src/page.html` 안의 `SESSIONS` 배열에 차시별로 들어 있습니다.
차시를 하나 고치려면 그 차시의 `SESSIONS.push({ ... })` 블록만 보면 됩니다.
OX 퀴즈는 `QUIZ` 객체에 차시 번호별로 들어 있습니다.
퀴즈는 `["문장", 1]` 형식이고 `1`이 ○, `0`이 ×입니다. 정답표와 점수는 자동으로 만들어집니다.

| 파일 | 역할 |
|---|---|
| `src/page.html` | 원본. 수업 내용 전체(`SESSIONS` 배열)와 디자인·인쇄 CSS |
| `index.html` | 빌드 결과물. GitHub Pages가 이 파일을 서빙 |
| `build.js` | 원본에 HTML 문서 껍데기를 입혀 `index.html` 생성 |
